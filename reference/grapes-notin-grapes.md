# Inverse of 'in' call

Calculates the set of entries not present in the second vector. Added
for convenience since this is not supported by default in R.

## Usage

``` r
a %notin% b
```

## Arguments

- a:

  First [`vector`](https://rdrr.io/r/base/vector.html) object.

- b:

  Second [`vector`](https://rdrr.io/r/base/vector.html) object.

## Value

A [`vector`](https://rdrr.io/r/base/vector.html) of
[`logical`](https://rdrr.io/r/base/logical.html) entries of `'a'` not
present in `'b'`.
